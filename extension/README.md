# Focus Guard 2.0 — Browser Extension (Chrome / Edge / Brave)

In-Page Adaptive Digital-Wellbeing Interventions directly over the screen of distracting apps and websites with **Direct Productive Teleportation**, **Chatting Detection**, and **1-Minute Tab Freeze Penalty**.

---

## 🎯 How Interventions Work Over Distracting Sites

When you visit a distracting site (such as **Instagram Reels, YouTube Shorts, WhatsApp Web, Discord, TikTok, Reddit**, etc.) during an active focus session, the intervention displays **directly over the screen of the distracting page itself**:

1. **Level 1 — In-Page Awareness Banner**:
   - A floating glassmorphic pill banner slides down at the top of the distracted page:
   - *"💡 Gentle Awareness: Still on track for 'Prepare for my Data Structures exam'? You've been on Instagram for 45s."*
   - Includes **"🚀 Launch Goal Workspace"** to teleport immediately.

2. **Level 2 / 3 — In-Page "Mind Mirror" AI Conscience Modal**:
   - Speaks as your own rational inner conscience:
     - *Reels/Shorts*: *"Deep down you know 1 reel turns into 45 minutes of regret. Let's switch right now."*
     - *WhatsApp/Discord*: *"Replying right now breaks your flow state. These messages will still be here when you finish."*
   - **Primary Action (Instant Teleport)**:
     - **🚀 Launch Target Resource Now** (e.g., Striver DSA Trees Lecture on YouTube or LeetCode Problemset):
       Closes the distracting Instagram / Shorts / WhatsApp tab and immediately opens the declared learning workspace!
     - 🧘 **Take 3-Min Breath Reset**
     - ⏸️ **Take 5-Min Scheduled Break**
     - ✕ **Dismiss (Snooze 60s)**

3. **In-Page Guided 3-Minute Breath Reset Screen**:
   - Opens an interactive, full-viewport mindfulness screen **directly inside the distracted tab**:
   - Features the animated **Breathing Orb** (4s inhale expansion, 4s exhale contraction), live `03:00` countdown, and soothing ambient lighting.
   - Completing the reset verifies recovery in the Focus Guard 2.0 engine, unlocks the screen, and grants a grace period to return to work.

4. **🥶 1-Minute Tab Freeze Penalty (Excess Distraction Lockout)**:
   - Triggered automatically on excessive digital distractions (Instagram Reels, YouTube Shorts, or unauthorized social texting):
   - Completely locks interaction and scrolling on the offending tab.
   - Displays a prominent frozen-glass countdown timer (`01:00`).
   - **Emergency Escape**: Click **"🚀 Teleport to Goal Workspace"** to end the penalty early and immediately jump back to your study or work session.

5. **Level 4 — In-Page Focus Lock Restriction Shield**:
   - Engaged if earlier suggestions are repeatedly ignored or if return-to-goal commitments are broken:
   - Pauses media, locks scrolling, and provides quick teleport options via **"🚀 Teleport to Goal Workspace"**, Breath Reset, PIN (default `1234`), or tab closure.

6. **🔇 100% Silent & Peaceful**:
   - Zero noisy alarms or buzzers. All interventions are quiet, elegant, and purely visual to avoid adding stress or breaking household/office silence.

## 🎛️ Extension Popup Features

Clicking the Focus Guard 2.0 extension icon in your browser toolbar reveals the companion widget:
- **👤 Who's Watching**: Displays active biometric status (e.g., *Owner (Watching)*, *Guest Paused*, or *Not Enrolled*).
- **Session Status**: Shows current session mode (`FLOW STATE`, `DRIFT_WARNING`, `COMPLETED`).
- **Distraction Risk Meter**: Real-time 0–100% risk score and level.
- **Drift State**: Live drift classification (`Nominal`, `Mild`, `Moderate`, `Acute`).
- **🥶 Tab Freeze Indicator**: Live timer when a freeze penalty is active.
- **Quick Controls**:
  - `🥶 Trigger 1-Min Freeze Punishment` (for testing/demo)
  - `Take 3-Min Breath Reset`
  - `Take 5-Min Break`
  - `Open 2.0 Web Dashboard` (opens `http://127.0.0.1:8000`)

## 🚀 How to Install or Reload in Chrome / Edge / Brave

1. Open **Google Chrome** (or Edge / Brave / Opera).
2. Navigate to:
   ```
   chrome://extensions
   ```
3. In the top-right corner, turn ON **"Developer mode"**.
4. If installing for the first time: Click **"Load unpacked"** and select:
   ```
   FocusGuard2.0\extension
   ```
   *(or the absolute path on your machine)*
5. If already installed: Click the **↻ (Reload icon)** on the "Focus Guard 2.0" extension card.
6. Focus Guard 2.0 is now live and actively guarding your focus!
