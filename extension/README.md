# Focus Guard 2.0 — Browser Extension (Chrome / Edge / Brave)

In-Page Adaptive Digital-Wellbeing Interventions directly over the screen of distracting apps and websites with **Direct Productive Teleportation** and **Chatting Detection**.

---

## 🎯 How Interventions Work Over the Distracted App

When you visit a distracting site (such as **Instagram Reels, YouTube Shorts, WhatsApp Web, Discord, TikTok, Reddit**, etc.) during an active focus session, the intervention displays **directly over the screen of the distracting page itself**:

1. **Level 1 — In-Page Awareness Banner**:
   - A floating glassmorphic pill banner slides down at the top of the distracted page:
   - *"💡 Gentle Awareness: Still on track for 'Prepare for my Data Structures exam'? You've been on Instagram for 45s."*
   - Includes **"🚀 Launch Striver DSA Lecture"** to teleport immediately.

2. **Level 2 / 3 — In-Page "Mind Mirror" AI Conscience Modal**:
   - Speaks as your own rational inner conscience:
     - *Reels/Shorts*: *"Deep down you know 1 reel turns into 45 minutes of regret. Let's switch right now."*
     - *WhatsApp/Discord*: *"Replying right now breaks your flow state. These messages will still be here when you finish."*
   - **Primary Action (Instant Teleport)**:
     - **🚀 Launch Target Resource Now** (e.g., Striver DSA Trees Lecture on YouTube or LeetCode Problemset):
       Closes the distracting Instagram / Shorts / WhatsApp tab and immediately opens the declared learning workspace!
     - 🧘 **Take 3-Min Breath Reset**
     - ⏸️ **Take 5-Min Scheduled Break**
     - ✕ **Dismiss (Snooze 60s)**

3. **In-Page Guided 3-Minute Breath Reset Screen**:
   - Opens an interactive, full-viewport mindfulness screen **directly inside the distracted tab**:
   - Features the animated **Breathing Orb** (4s inhale expansion, 4s exhale contraction), live `03:00` countdown, and soothing ambient lighting.
   - Completing the reset verifies recovery in the Focus Guard 2.0 engine, unlocks the screen, and grants a grace period to return to work.

4. **Level 4 — In-Page Focus Lock Restriction Shield**:
   - Engaged only if earlier suggestions are repeatedly ignored or if return to goal was broken:
   - Pauses media, locks scrolling, and provides quick teleport options via **"🚀 Teleport to Goal Workspace"**, Breath Reset, PIN (default `1234`), or tab closure.

## 🚀 How to Install or Reload in Chrome/Edge

1. Open **Google Chrome** (or Edge / Brave / Opera).
2. Go to:
   ```
   chrome://extensions
   ```
3. In the top right corner, turn ON **"Developer mode"**.
4. If already installed: Click the **↻ (Reload icon)** on the "FocusGuard - Tab Distraction Shield" card.
   If installing for the first time: Click **"Load unpacked"** and select:
   ```
   c:\Users\Eshan Sharma\OneDrive\문서\Desktop\FocusGuard2.0\extension
   ```
5. Focus Guard 2.0 is now live and actively guarding your focus!
